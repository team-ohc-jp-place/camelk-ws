== OpenShift Devspaces について

本ワークショップの開発環境は、オープンソースの link:https://www.eclipse.org/che/[Eclipse Che,window="_blank"] プロジェクトに基づいた、OpenShift Container Platform で動作するWebベースの統合開発環境(IDE)である、link:https://developers.redhat.com/products/openshift-dev-spaces/overview[Red Hat OpenShift DevSpaces,window="_blank"] を使用します。

* OpenShift DevSpaces の特徴とメリット
** **Web IDE**: ブラウザ上で動作するためソフトウェアのインストールが不要でインターネットで接続されていればどこからでも開発が可能
** **高い拡張性**: オンラインのOpen VSX レジストリーからプラグインがインストール可能で、開発言語に応じた拡張が可能
** **標準化**: DevFileと開発用コンテナイメージによって、開発環境を標準化することが可能
** **開発の一貫性**: 開発中環境から商用環境まで、アプリケーションが同じOS、同じコンテナイメージで動作することで、環境に依存したトラブルを軽減
** **セキュリティ向上**: アプリケーションコードを含むデータがオンライン上で保存されるため、ストレージの故障リスクや盗難リスクが激減

OpenShift Web Console にアクセスするための情報は以下の通りです。

* *Username*: {{ USER_ID }}
* *Password*: {{ OPENSHIFT_PASSWORD }}

image::workshop-environment/09-devspaces-002.png[width="800px"]

OpenShift Web Console にログイン後、左のメニューから `Developer` パースペクティブを選択し、その下のメニューから `Topology` ビューを開きます。Project名は `{{ USER_ID }}-dev` を選択してください。

image::workshop-environment/09-devspaces-003.png[width="1200px"]

=== リソースについて

* *guides*: 本ワークショップのガイドドキュメント
* *kafka-cluster*: Kafka のクラスター
* *kafdrop*: Kafka 用の Web UI でブローカーやトピックなどの情報やメッセージの表示を行います
* *postgresql*: サンプルデータが格納されたPostgreSQL
* *postgresql-replica*: Debeziumを使用してデータを同期をするPostgreSQL
* *debezium*: データベースの更新をイベントに変換する Change Data Capture
* *minio*: Amazon S3と互換性のあるオブジェクト・ストレージ・サーバー

あらかじめ、KafkaやPostgreSQLといったリソースが用意されています。
ワークショップの中で、これらのデータソースを用いた連携をCamel Kで作成していきます。

=== OpenShift DevSpaces へのログイン

こちらのリンクから、link:{{ DEVSPACES_URL }}[OpenShift DevSpaces Dashboard] にログインします。

初回にアクセスすると、以下のような画面が表示されますので、`Log In with OpenShift` をクリックします。

image::workshop-environment/09-devspaces-005.png[width="600px"]

OpenShift Devspaces にアクセスするための情報は以下の通りです。

* *Username*: {{ USER_ID }}
* *Password*: {{ OPENSHIFT_PASSWORD }}

image::workshop-environment/09-devspaces-002.png[pic, 800]

ログインに成功すると、以下のような画面が表示されますので、`Allow selected permissions` をクリックしてください。

image::workshop-environment/09-devspaces-006.png[pic, 600]

OpenShift DevSpaces の Dashboard が表示されます。

今回のハンズオン環境を含むワークスペースが作成されていると思いますので、右側の `Open` をクリックしてワークスペースを開いてください。

image::workshop-environment/09-devspaces-019.png[pic, 800]

以下のような画面にジャンプします。
`Yes, I trust the authors` をクリックします。その後、`Mark Done` をクリックしてください。
（エディタの外観を変えたい方は、設定を変更してみてください）

image::workshop-environment/09-devspaces-020.png[pic, 400]
image::workshop-environment/09-devspaces-021.png[pic, 400]

OpenShift DevSpacesのワークスペースのエクスプローラ上で右クリックをすると、ポップアップメニューが開きます。

image::workshop-environment/09-devspaces-022.png[pic, 1200]

`Open in Integrated Terminal` から、開発環境のターミナルを開くことができます。

image::workshop-environment/09-devspaces-023.png[pic, 1200]
