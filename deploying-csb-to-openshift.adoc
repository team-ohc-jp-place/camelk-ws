== 1. Camel for Springboot を OpenShift へデプロイする

このセクションでは、Camel for Springboot にエクスポートして、OpenShiftへデプロイする方法について確認します。

デプロイするサンプルは、`labs/dice-roll.yaml` を使います。
左のエクスプローラー上で、`labs/dice-roll.yaml` 右クリックをして、メニューから `Open with Kaoto Graphical Editor for Camel` を選択し、Kaoto のグラフィカルエディターを開きます。

以下のような Route が設定されています。

image::app2/openshift-001.png[pic,600]

内容については次の通りです。

image::app2/openshift-002.png[pic,800]

---

まずは、このサンプルのDSLを Camel for Springboot の mavenプロジェクト にエクスポートします。
OpenShift DevSpaces のターミナルで、以下のコマンドを実行してください。

[source, bash]
----
cd labs
camel export dice-roll.yaml --runtime=spring-boot --gav=com.sample:dice-roll:1.0 --directory=../mycsb-project
----

ルートディレクトリに、`mycsb-project` というフォルダが作成されます。

image::app3/openshift-003.png[pic,1200]

---

アプリケーションを OpenShift Container Platform クラスター内で実行されるコンテナーイメージとしてビルドし、デプロイするため、プロジェクトの `pom.xml` に設定を追加する必要があります。

`mycsb-project/pom.xml` をエディタで開き、以下の設定を追加してください。

100行目付近の `<profiles>` ~ `</profiles>` の間に追加します。 

[source, bash]
----
        <profile>
            <id>openshift</id>
            <properties>
                <sbProfile>openshift</sbProfile>
                <jkube.generator.from>registry.access.redhat.com/ubi8/openjdk-17</jkube.generator.from>
            </properties>
            <activation>
                <property>
                    <name>openshift</name>
                </property>
            </activation>
            <dependencies>
                <dependency>
                    <groupId>org.apache.camel.springboot</groupId>
                    <artifactId>camel-kubernetes-starter</artifactId>
                </dependency>
            </dependencies>
            <build>
                <plugins>
                    <plugin>
                        <artifactId>openshift-maven-plugin</artifactId>
                        <groupId>org.eclipse.jkube</groupId>
                        <executions>
                            <execution>
                                <goals>
                                    <goal>resource</goal>
                                    <goal>build</goal>
                                    <goal>deploy</goal>
                                </goals>
                            </execution>
                        </executions>
                        <configuration>
                            <resources>
                                <replicas>1</replicas>
                                <serviceAccount>camel-user</serviceAccount>
                            </resources>
                        </configuration>
                    </plugin>
                </plugins>
            </build>
        </profile>
----

---

OpenShift にデプロイする準備が整いました。

OpenShift DevSpaces のターミナルで、Springbootのプロジェクトフォルダに入り、以下のコマンドを実行してください。

[source, bash]
----
oc project {{ USER_ID }}-dev
mvn clean package -Popenshift
----

ビルドとデプロイに成功すると、以下のメッセージが表示されます。

image::app3/openshift-006.png[pic,800]

OpenShiftにアクセスをして、デプロイができているか確認をします。

以下のURLにアクセスをしてみてください。

* link:https://console-openshift-console.{{ ROUTE_SUBDOMAIN }}/topology/ns/{{ USER_ID }}-dev?view=graph[https://console-openshift-console.{{ ROUTE_SUBDOMAIN }}/topology/ns/{{ USER_ID }}-dev?view=graph, window="_blank"]

認証情報を求められた場合は、以下の情報を入力します。

* username: {{ USER_ID }}
* password: {{ OPENSHIFT_PASSWORD }}

Topology上に、`dice-roll` のアプリケーションがデプロイされているはずです。

image::app3/openshift-007.png[pic,400]

以下のURLにアクセスをしてみてください。

* link:http://dice-roll-{{ USER_ID }}-dev.{{ ROUTE_SUBDOMAIN }}/dice-roll[https://dice-roll-{{ USER_ID }}-dev.{{ ROUTE_SUBDOMAIN }}/dice-roll,window="_blank"]

ブラウザ上に、dice-rollのランダムな1~6の整数が表示されます。

image::app2/openshift-008.png[pic,800]

---

以上、Camel DSL を Springboot プロジェクトにエクスポートして、OpenShiftにデプロイする方法について確認しました。
