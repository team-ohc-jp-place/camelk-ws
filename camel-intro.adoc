== Red Hat build of Apache Camel 概要

Apache Camelというのは分散インテグレーションを実現するための機能を提供するオープンソースのフレームワークです。
様々なシステムに対応したコネクタを標準で提供しており、データフォーマットの変換やプロトコル変換を行うためのコンポーネントも用意されているので、
システム連携を簡単に行うことができ、かつ軽量に実行することができるようになります。

== Apache Camel の特徴

Apache Camelは、システム連携に必要な様々な機能を連携部品として多数提供しています。
データフォーマットやプロトコルの変換を行うための部品や、様々なシステムにアクセスするためのコネクターが再利用可能なコンポーネントとして用意されており、さらにシステム連携のデザインパターンであるEnterprise Integration Patternsも連携部品として利用することができます。
これらの連携部品は300以上あり、それらを組み合わせることで連携フローを簡単に実装することができるようになります。

== Apache Camel の連携の実装方式

Apache CamelはJavaベースで開発されていますが、連携フローを実装する場合には、JavaやXML、あるいはYAMLなどでDSLを使用することができ、Camelベースのアプリケーションを簡潔な表現で実装することができます。
