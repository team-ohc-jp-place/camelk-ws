:experimental:
:tip-caption: :bulb:
:imagesdir: images

== 1.目的

link:https://camel.apache.org/components/{{ CAMEL_VERSION }}/sftp-component.html[SFTP コンポーネント,window="_blank"] は、SFTPプロトコルでリモートファイルシステムにアクセスすることができます。
SFTPコンポーネントを使用して、ファイル取得し他のシステムに連携したり、他のコンポーネントからのデータをリモートファイルシステムに格納する方法について理解します。

== 2.リモートファイルシステムへアクセスする

SFTPサーバを OpenShift に構築しています。実際にアクセスできるか確認をしてみましょう。
OpenShift DevSpaces のターミナルで、以下のコマンドを実行します。

[source, bash]
----
sftp {{ USER_ID }}@sftp-service.sftp.svc
----

* 認証情報
 * ID: {{ USER_ID }}
 * Password: openshift

image::sftp/sftp-001.png[pic, 800]

初回のアクセス時には、接続を許可するか問われますので、`yes` と入力します。
次に、Password を確認されますので、`openshift` と入力してください。

ログインに成功すると、コンソールから `ls` コマンドを実行して、`upload` というフォルダがあることを確認してください。

[TIP]
====

[cols="4,7",options="header",role="custom-table"]
|===
| SFTPの内部コマンド | 意味
| bye | sftpを終了する（exitでも同じ意味になる）
| cd [パス] | サーバー側のカレントディレクトリを変更する
| get [ファイル] | サーバー上のファイルをローカルにダウンロードする
| help | ヘルプを表示する（「?」も同じ意味になる）
| lcd [パス] | ローカル側のカレントディレクトリを変更する
| lls | ローカル側のファイルリストを表示する
| ln | シンボリックリンクを作成する
| lpwd | ローカル側のカレントディレクトリを表示する
| ls | サーバー側のファイルリストを表示する
| mkdir [ディレクトリ] | サーバー側にディレクトリを作成する
| put [ファイル] | ローカルのファイルをサーバーへアップロードする
| pwd | サーバー側のカレントディレクトリを表示する
| rename [旧ファイル] [新ファイル] | サーバー側のファイルを新しい名前に変更する
| rm [ファイル] | サーバー側のファイルを削除する
|===

====

接続したSFTPサーバの公開鍵が、`known_hosts` ファイルに登録されます。
ファイルのパスは、`/home/user/.ssh/known_hosts` です。

== 3.SFTPコンポーネントを使ってファイルをSFTPサーバへ格納する

それでは、まず Camel で ファイルをSFTPサーバへ格納する処理を作成してみます。

OpenShift DevSpaces 左のエクスプローラー上で、右クリックをして、メニューから `New File...` を選択し、`sftp.yaml` と入力して `Enter` を押してください。
今度は作成したファイルを選択して右クリックし、`Open with Kaoto Graphical Editor for Camel` から Kaoto のグラフィカルエディターを開きます。

まだ Route の定義がないので、新しくRouteを作成します。
`+ New` をクリックしてください。

image::sftp/sftp-002.png[pic, 600]

`timer` と `log` が配置された Route が作成されます。

`timer` コンポーネントは、デフォルトでは1秒ごとに起動する設定になっています。
`timer` シンボルをクリックすると、右側にプロパティが表示されます。
`Reapet Count` は無指定だとプロセス停止まで繰り返しますので、`1` を指定してください。

image::sftp/sftp-003.png[pic, 600]

次に、SFTPサーバに格納するファイルの中身を編集します。

`Setbody` コンポーネントを使いますので、`log` と入れ替えます。
`log` シンボルの メニューをクリックし、`Replace` を選択します。

image::sftp/sftp-004.png[pic, 600]

コンポーネントのカタログが開きます。

`Type: Processor` の中から `setBody` を探して選択をしてください。
左上のテキストボックスに `setBody` と入力をすると、絞り込みができます。

image::sftp/sftp-005.png[pic, 600]

`log` が `setBody` と入れ替わりました。

`setBody` のシンボルをクリックして、`Expression` のエンピツのマークをクリックします。

image:sftp/sftp-006.png[pic, 800] 

image:sftp/sftp-007.png[pic, 800]

====

====

次に、SFTPサーバに格納するファイル名を動的に指定する方法を確認します。

Headerに、`CamelFileName` という項目を保持しておくと、SFTPコンポーネントにその値を設定することができます。

`setBody` シンボルの メニューをクリックし、`Append` を選択します。

image:sftp/sftp-008.png[pic, 800]

`Type: Processor` の中から `setHeader` を探して選択をしてください。
左上のテキストボックスに `setHeader` と入力をすると、絞り込みができます。

image:sftp/sftp-009.png[pic, 800]

`setheader` のシンボルをクリックして、Parameterに以下の項目を設定します。

* Experssion: ${date-with-timezone:now:JST:yyyyMMddHHmmss}.txt
* Name: CamelFileName

image:sftp/sftp-010.png[pic, 800]

次に、`sftp` コンポーネントを配置して、SFTPサーバにファイルを格納する処理を実装します。
`setHeader` シンボルの メニューをクリックし、`Append` を選択します。

image:sftp/sftp-011.png[pic, 800]

`Type: Component` の中から `sftp` を探して選択をしてください。
左上のテキストボックスに `sftp` と入力をすると、絞り込みができます。

image:sftp/sftp-012.png[pic, 800]

`sftp` シンボルをクリックすると、右側にプロパティが表示されますので、以下のParametersを設定してください。

* Endpoint Properties
 * Host: sftp-service.sftp.svc
 * Port: 22
 * Directory Name: upload
* Security Properties
 * Known Hosts File: /home/user/.ssh/known_hosts
 * Username: {{ USER_ID }}
 * Password: openshift

image:sftp/sftp-013.png[pic, 800]

それでは、実際に動かしてみます。
OpenShift DevSpaces のターミナルで、以下のコマンドを実行してください。

[source, bash]
----
camel run sftp.yaml
----

image:sftp/sftp-014.png[pic, 1200]

Camelが起動したら、実際にSFTPサーバにファイルが格納されているか確認をしてみます。
SFTPサーバにアクセスをしたターミナルを開き、`upload` フォルダの中身を確認してみてください。

image:sftp/sftp-015.png[pic, 600]

確認後、`Ctrl+C`、もしくはターミナル右上のゴミ箱のアイコンをクリックして、Camel を終了してください。

== SFTPコンポーネントを使ってSFTPサーバからファイルを受信する

Kaotoのグラフィカルエディターで先ほどの `sftp.yaml` を開き、上部メニューの `New` -> `Route` をクリックしてください。

image:sftp/sftp-016.png[pic, 800]

新しいRouteが作成されます。
上部メニューのRouteから、既存のRouteの表示、非表示の切り替えができます。

image:sftp/sftp-017.png[pic, 800]

新しいRouteの `timer` シンボルの メニューをクリックし、`Replace` を選択します。

image:sftp/sftp-018.png[pic, 800]

`Type: Component` の中から `sftp` を探して選択をしてください。
左上のテキストボックスに `sftp` と入力をすると、絞り込みができます。

image:sftp/sftp-012.png[pic, 800]

`sftp` シンボルをクリックすると、右側にプロパティが表示されますので、以下のParametersを設定してください。

* Endpoint Properties
 * Host: sftp-service.sftp.svc
 * Port: 22
 * Directory Name: upload
* Filter Properties
 * Move: processed
* Security Properties
 * Known Hosts File: /home/user/.ssh/known_hosts
 * Username: {{ USER_ID }}
 * Password: openshift

`move` プロパティは、受信したSFTPサーバ側のファイルを、指定したフォルダへ移動させます。

image:sftp/sftp-019.png[pic, 800]

次に、`log` で出力するメッセージを修正します。
`log` シンボルをクリックすると、右側にプロパティが表示されますので、確認してください。
`Message` に `template message` と入力されていますので、これを `${body} \ ${headers}` に変更してください。
これで、ファイルで受信したメッセージの本文やファイル名などの情報をログに出力するようになります。

image:sftp/sftp-020.png[pic, 800]

それでは、実際に動かしてみます。
OpenShift DevSpaces のターミナルで、以下のコマンドを実行してください。

[source, bash]
----
camel run sftp.yaml
----

image:sftp/sftp-021.png[pic, 1200]

Camelが起動したら、ターミナルのログを確認してください。

Camelの起動ログに続き、2つのファイルの受信ログが表示されていると思います。
先ほどSFTPサーバに格納したファイル、2つ目は今起動したCamelのTimerトリガーで新たに格納されたファイルを受信しています。

SFTPサーバにアクセスをしたターミナルを開き、`upload` フォルダの中身が空であること、`processed`に受信したファイルが移動していることを確認してください。

image:sftp/sftp-022.png[pic, 600]

確認後、`Ctrl+C`、もしくはターミナル右上のゴミ箱のアイコンをクリックして、Camel を終了してください。
