== 目的

link:https://camel.apache.org/components/{{ CAMEL_VERSION }}/eips/marshal-eip.html[Marshal] と 
link:https://camel.apache.org/components/{{ CAMEL_VERSION }}/eips/unmarshal-eip.html[Unmarshal] を使用して、Camel におけるデータ形式変換の方法を理解する事を目的とします。

* **Marshal** - Message の Body の Javaオブジェクトをバイナリやテキスト形式に変換します。
* **Unmarshal** - Message の Body の バイナリやテキスト形式のデータをJavaオブジェクトに変換します。

image::data-formats/MessageTranslator.gif[] 

Apache Camel が提供する Data Format については、link:https://camel.apache.org/components/{{ CAMEL_VERSION }}/dataformats/index.html[こちら] を参照してください。

== CSVファイルを Unmarshal でJavaオブジェクトに変換する

OpenShift DevSpaces 左のエクスプローラー上で、右クリックをして、メニューから `New File...` を選択し、`dataformats.yaml` と入力して `Enter` を押してください。

作成したファイルをソースコードエディターで開き、以下のコードをコピーしてペーストしてください。

[source, yaml]
----
- route:
    from:
      uri: file:data/input
      steps:
        - log:
            message: ${body}
----

image::data-formats/dataformats-001.png[] 

次に、作成した `dataformats.yaml` を選択して右クリックし、`Open with Kaoto Graphical Editor for Camel` からKaotoのグラフィカルエディターを開きます。

`file` と `log` が配置されているRouteが開きます。

image::data-formats/dataformats-002.png[] 

`file` の `Directory Name` は、先ほどのモジュールと同様に、`data/input` が設定されています。

テスト用のCSVファイルは、`file` フォルダに `test_02_dataformats.csv` というファイルが用意されていますので、それを使用します。

ファイルの中身は、

----
  id,name
  1,apple
  2,orange
  3,lemon
----

というテキストが格納されています。

image::data-formats/dataformats-003.png[] 

では、取得するファイルの中身を変換していきます。
まず、オブジェクトに変換するために、`unmarshal` をRouteに配置します。

`log` シンボルのメニューをクリックして、`Append` を選択します。

image::data-formats/dataformats-004.png[] 

コンポーネントのカタログが開きますので、先ほどと同じように `Type: Processor` の中から `Unmarshal` を探して選択をしてください。
左上のテキストボックスに `Unmarshal` と入力をすると、絞り込みができます。

image::data-formats/dataformats-005.png[] 

`unmarshal` のシンボルが `log` に続いて配置されます。

Parameters は、以下のように設定をしてください。
他の項目は、デフォルトのままで構いません。

* **Data Format**: csv
* **Delimiter**: , (カンマ)
* **Use Maps**: True

image::data-formats/dataformats-006.png[] 
image::data-formats/dataformats-007.png[] 

続いてデータ変換後の Body を 確認するための `log` を追加します。

`unmarshal` シンボルのメニューをクリックして、`Append` を選択します。

image::data-formats/dataformats-008.png[] 

コンポーネントのカタログが開きますので、`Type: Processor` の中から `Log` を探して選択をしてください。

image::data-formats/dataformats-009.png[] 

`unmarshal` で変換した内容を表示するには、`log` プロパティ の `Message` に `${body}` と入力をしてください。

image::data-formats/dataformats-010.png[] 

それでは、実際に動かしてみます。
OpenShift DevSpaces のターミナルで、以下のコマンドを実行してください。

[source, bash]
----
camel run dataformats.yaml
----

image::data-formats/dataformats-011.png[] 

Camelが起動したら、テスト用のCSVファイルを受信先のフォルダに格納して動かしてみます。

`file` フォルダにある `test_02_dataformats.txt` をコピーし、`data/input` フォルダにペーストします。

image::data-formats/dataformats-012.png[] 

ファイルが所定のフォルダに格納されると、インテグレーションが実行されて、コンソールに ファイルの本文と、`unmarshal` で変換した後の Log が表示されます。
（格納したファイルは、デフォルトの設定では `data/input` 配下に `.camel` フォルダが作成され、そちらに移動します）

CSV Data Format で Unmarshal したデータは、JavaのList型になります。

image::data-formats/dataformats-013.png[] 

Log の確認ができたら、`Ctrl+C`、もしくはターミナル右上のゴミ箱のアイコンをクリックして、Camel を終了してください。

== Marshal でJSON形式のテキストに変換する

先ほど作成した `dataformat.yaml` に、JSON形式のテキストに変換する処理を追加してみます。

Kaoto のグラフィカルエディターにて、２つ目の `log` シンボルのメニューをクリックして、`Append` を選択します。

image::data-formats/dataformats-014.png[]

コンポーネントのカタログが開きますので、`Type: Processor` の中から `Marshal` を探して選択をします。
左上のテキストボックスに `Marshal` と入力をすると、絞り込みができます。

image::data-formats/dataformats-015.png[]

`marshal` のシンボルが `log` に続いて配置されます。

Parameters は、以下のように設定をしてください。
他の項目は、デフォルトのままで構いません。

* **Data Format**: json

image::data-formats/dataformats-016.png[]

続いてデータ変換後の Body を 確認するための `log` を追加します。

`marshal` シンボルのメニューをクリックして、`Append` を選択します。

image::data-formats/dataformats-017.png[] 

コンポーネントのカタログが開きますので、`Type: Processor` の中から `Log` を探して選択をします。

image::data-formats/dataformats-009.png[] 

`marshal` で変換した内容を表示するため、`log` プロパティ の `Message` に `${body}` と入力をします。

image::data-formats/dataformats-018.png[] 

それでは、実際に動かしてみます。
OpenShift DevSpaces のターミナルで、以下のコマンドを実行してください。

[source, bash]
----
camel run dataformats.yaml
----

Camelが起動したら、先ほどと同様に、`file` フォルダにある `test_02_dataformats.txt` をコピーし、`data/input` フォルダにペーストします。

image::data-formats/dataformats-012.png[] 

ファイルが所定のフォルダに格納されると、インテグレーションが実行されて、コンソールに ファイルの本文と、`unmarshal` でオブジェクトに変換したBody、
`marshal` でJSONに変換したBody、の Log が表示されます。（格納したファイルは、デフォルトの設定では `data/input` 配下に `.camel` フォルダが作成され、そちらに移動します）

JSON Data Format で Marshal したデータは、JSON形式のテキストになります。

image::data-formats/dataformats-019.png[] 

Logの確認後、`Ctrl+C` もしくは、ターミナル右上のゴミ箱のアイコンをクリックして、終了してください。
