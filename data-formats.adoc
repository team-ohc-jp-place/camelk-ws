== 1. Marshal と Unmarshal について 

Apache CamelにおけるMarshalとUnmarshalは、データの変換とフォーマットに関する重要な機能です。
以下に、それぞれの概要と使用方法について説明します。

* link:https://camel.apache.org/components/{{ CAMEL_VERSION }}/eips/marshal-eip.html[Marshal, window="_blank"]
** オブジェクトを特定のフォーマットに変換するプロセスです。Camelでは、さまざまなフォーマットへのマーシャリングをサポートしており、これによりデータをエクスポートしやすくなります。
** 例: オブジェクト → XML、JSON、CSVなど
* link:https://camel.apache.org/components/{{ CAMEL_VERSION }}/eips/unmarshal-eip.html[Unmarshal, window="_blank"]
** 特定のフォーマットからオブジェクトに変換するプロセスです。これにより、例えばXMLやJSONなどのデータをオブジェクトに変換して処理することが可能です。
** 例: XML、JSON、CSVなど → オブジェクト

image::dataformats/MessageTranslator.gif[pic, 400]

Apache Camel が提供する Data Format については、link:https://camel.apache.org/components/{{ CAMEL_VERSION }}/dataformats/index.html[こちら, window="_blank"] を参照してください。

== 2. CSV形式のテキストを Unmarshal でJavaオブジェクトに変換する

左のエクスプローラー上で、`labs/dataformats.yaml` 右クリックをして、メニューから `Open with Kaoto Graphical Editor for Camel` を選択し、Kaoto のグラフィカルエディターを開きます。

以下のような Route が設定されています。

image::dataformats/dataformats-001.png[pic,600] 

内容については次の通りです。

image::dataformats/dataformats-002.png[pic,800] 

* `timer` コンポーネント: 指定した間隔でメッセージを生成します。
** `uri`: `timer:dataformats` はタイマーの名前を指定しており、ユニークであれば任意の文字列でかまいません。
** `repeatCount`: このルートが実行される回数を指定します。`1`なので、一度だけ実行されます。
* `setBody`: メッセージのボディを手動で設定します。
** `simple`: Simple言語を使用してボディを設定します。この例では、CSV形式のテキストを設定しています。
* `log`: `${body}` は、メッセージボディをログに出力します。

このサンプルソースを動かしてみます。
OpenShift DevSpaces のターミナルで、以下のコマンドを実行してください。

[source, bash]
----
camel run labs/dataformats.yaml
----

`setBody`で設定したcsv形式のデータが、ログに表示されました。

image::dataformats/dataformats-003.png[pic,1200] 

ログ の確認後、`Ctrl+C`、もしくはターミナル右上のゴミ箱のアイコンをクリックして、Camel を終了してください。

---

では、まずCSV形式のデータをオブジェクトにを変換していきます。

`setBody` シンボルのメニューをクリックして、`Append` を選択します。

image::dataformats/dataformats-004.png[pic, 600]

コンポーネントのカタログが開きますので、 `Type: Processor` の中から `Unmarshal` を探して選択をしてください。
左上のテキストボックスに `Unmarshal` と入力をすると、絞り込みができます。

image::data-formats/dataformats-005.png[pic, 600]

`unmarshal` のシンボルが `setBody` に続いて配置されます。

Parameters は、以下のように設定をしてください。
他の項目は、デフォルトのままで構いません。

* **Data Format**: csv
* **Delimiter**: , (カンマ)
* **Use Maps**: True

image::dataformats/dataformats-006.png[pic, 800]
image::dataformats/dataformats-007.png[pic, 800]


それでは、ここで実行して確認をしてみます。
OpenShift DevSpaces のターミナルで、以下のコマンドを実行してください。

[source, bash]
----
camel run labs/dataformats.yaml
----

CSV形式のデータが、Unmarshal で、オブジェクトに変換されました。

image::dataformats/dataformats-008.png[pic, 1200]

ログ の確認後、`Ctrl+C`、もしくはターミナル右上のゴミ箱のアイコンをクリックして、Camel を終了してください。

image::dataformats/dataformats-009.png[pic, 600]

image::dataformats/dataformats-010.png[pic, 600]

`marshal` のシンボルが `unmarshal` に続いて配置されます。

Parameters は、以下のように設定をしてください。
他の項目は、デフォルトのままで構いません。
